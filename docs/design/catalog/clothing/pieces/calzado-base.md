# Calzado base

**Tipo:** prenda de un conjunto.
**Estado de diseño:** aprobada para función; apariencia concreta pendiente de aceptación visual.
**Conjunto:** [ropa-base](../sets/ropa-base.md).

## Diseño

Calzado sencillo oscuro del estado base. El uniforme equipado lo sustituye por su propio calzado.

## Criterios observables

Se muestra con su conjunto, deforma de forma coherente con el esqueleto y no deja restos al sustituir el uniforme. Calidad visible revisada en el personaje dentro de Godot.

## Rutas de producción

Piezas BaseShoes de art/source/characters/adventurer.blend; exportadas en assets/models/characters/adventurer.glb. El estado operativo está en [#35](https://github.com/Dioniss97/ShadowsOfKharuun/issues/35) y [#36](https://github.com/Dioniss97/ShadowsOfKharuun/issues/36).
