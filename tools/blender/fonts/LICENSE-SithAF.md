Shadows of Kharuun uses this fan interpretation of the Legends Kittât writing
system to render the English Sith Code requested by the user. It is a visual
transliteration, not a translation into the Sith language or a claim of official
Lucasfilm typography. The English text is attributed to the Star Wars fiction;
the original lettering is credited above.

Changes in the generated sculpture: glyph outlines are converted into mesh
cutters, fitted to the stole, shallowly incised into stone and coloured with
worn matte red pigment. The font file itself is not
modified. The resulting carved geometry is an adaptation of the lettering.
